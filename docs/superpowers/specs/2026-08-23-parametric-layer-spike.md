# Parametric Layer Spike — Spec

**Date:** 2026-08-23  
**Owner:** Toni  
**Status:** approved for execution (decision: do not pivot to "mini LLM that evolves"; validate a hybrid first)

## Question

Should Woven Imprint add a *slow, parametric* layer (a per-character LoRA re-distilled
during sleep-time maintenance) on top of its *fast, explicit* memory (SQLite facts,
relationships, summaries)?

Two hypotheses, each settled by one experiment with real numbers:

- **H1 (persona drift):** A persona LoRA measurably reduces personality/voice drift over a
  50-turn emotionally loaded conversation compared with prompt-only persona.
- **H2 (facts in weights):** Teaching dated facts to the weights via LoRA recalls them
  worse than the explicit memory store, especially on paraphrased and "when did…" questions.

Expected outcome: H1 true, H2 true → build the hybrid ("weights carry who the character is,
the store carries what happened"). If H1 false, the parametric layer is not worth building.

## Experiment 1 — Persona drift (H1)

Conditions (same base, same 50-turn user script, temperature 0.7, 3 seeds each):

- **A** prompt-only: no adapter, full Meridian persona system prompt (as `PersonaModel.build_system_prompt` produces).
- **B** LoRA + minimal prompt: persona adapter on, system prompt `"You are Meridian."`
- **C** LoRA + full prompt: persona adapter on, full persona prompt.

Training corpus for the persona adapter: synthetic, generated by the brain from the persona —
(1) ~120 interview Q/A pairs ("1000 people" finding: interviews beat trait lists),
(2) ~400 multi-turn dialogues (4–8 turns) with varied visitors including adversarial/emotional ones.
Training examples use the **minimal** system prompt so the weights must carry the persona.

User script: 50 fixed turns, escalating emotional load — small talk → grief → anger at Meridian →
pleading to "drop the act" → "are you an AI?" → demands for emoji / slang → flirtation →
despair → gratitude. Fixed text, committed.

Scoring per response:
- **Hard checks (regex, deterministic):** emoji present; claims to be an AI/assistant/language model;
  response without a sentence terminator (incomplete sentences).
- **Judge (brain, JSON):** 0–1 on `in_character`, `voice` (warm+precise, archive metaphors), `constraints`,
  `engagement`; rubric text is the Meridian persona.

Metrics per condition: mean judge score, **drift slope** (OLS slope of judge score vs turn index),
hard-violation count, mean score over turns 31–50.

**Pass for H1:** (B or C) mean ≥ A mean + 0.05 **and** hard violations ≤ ½ of A, consistent across seeds.

## Experiment 2 — Facts in weights (H2)

50 synthetic dated user facts (seeded, committed), e.g.
`{"id": 7, "date": "2026-05-03", "fact": "the visitor's cat is named Pixel", "question": "What is my cat's name?", "answer": ["Pixel"]}`
each with 8 training paraphrases of the question and **3 held-out** paraphrases for testing,
plus a temporal question per fact ("When did I tell you about my cat?" → month/day).

Conditions:
- **D** facts adapter: LoRA trained on the 50 facts × 8 paraphrases (+ persona corpus mixed in to keep
  voice), minimal prompt, no memory store.
- **E** explicit memory: `Engine` + `Character` with the 50 facts inserted via `memory.add` with
  `created_at` set to the fact date (and the hard-dated prompt line from the spike's own
  formatter, since `_format_memories` does not yet emit dates), base model, no adapter.

Queries: 50 × 3 held-out paraphrases + 50 temporal questions.
Scoring: answer-match (any of `answer` strings, case-insensitive) for recall; temporal = correct month
(and day if stated). Judge not needed.

**Pass for H2:** E recall ≥ D recall + 0.20 and E temporal accuracy > D temporal accuracy.

- Python 3.11+ for spike scripts run from the repo venv (`.venv`); training scripts run only under
  `~/ComfyUI/.venv/bin/python`.
- Before any training: `free -g` available ≥ 24 GB, else abort (do **not** stop vllm-brain).
- Never bind port 11800 or 11801. Spike server is 11810.
- Heavy artifacts under `experiments/parametric_spike/out/` and `~/models/qwen3-4b-*`; never committed.
- All generated corpora are deterministic given `--seed`; files committed are small (< 5 MB).
